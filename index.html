🔧 Setup Firebase — Satu Kali Sahaja

Dashboard ini guna Firebase Firestore untuk simpan data secara real-time. Ikut langkah berikut untuk setup percuma:

1
Pergi ke console.firebase.google.com Log masuk dengan Google account, klik "Add project", namakan projek (cth: ec1-analyzer), disable Google Analytics, klik Create.
2
Tambah Web App & aktifkan Firestore + Auth Dalam projek: klik ikon </> → register app → copy firebaseConfig. Kemudian: Build → Firestore Database → Create (Production mode). Build → Authentication → Get started → Email/Password → Enable.
3
Set Firestore Rules (Firestore → Rules) Paste rules ini dan klik Publish:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
4
Paste Firebase Config di sini Copy keseluruhan objek firebaseConfig dari Firebase Console:
💡 Untuk admin sahaja. Selepas setup ini, salin nilai firebaseConfig dan paste terus ke dalam pembolehubah FIREBASE_CONFIG dalam fail index.html (cari baris const FIREBASE_CONFIG). Dengan cara ini, semua pengguna lain tidak perlu buat setup ini — mereka terus boleh daftar dan login.
